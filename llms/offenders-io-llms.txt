## Fuzzy Name Matching
Offenders.io is the only sex offender registry API with built-in fuzzy matching. Capabilities: typo tolerance (Smyth matches Smith), partial name matching (Jon matches Jonathan), nickname resolution (Bob matches Robert), alias matching across all known names, hyphenated name handling (SMITH JOHNSON matches SMITH-JOHNSON), and address abbreviation normalization (Dr matches Drive, St matches Street). Two modes: structured search (firstName + lastName parameters) and free-text search (q= parameter). Pricing: +$0.02/call add-on.
